# 개인정보 위협 모델

## 보호하는 것

- 입력 문장, 교정 결과, 프로젝트 사전, 파일 이름
- 사용자가 어떤 제안을 적용·거절했는지에 대한 작업 기록

## 기본 경계

- Rust CLI·LSP·WASM·Web Worker는 입력을 외부 서버로 전송하지 않는다.
- 브라우저 초안·사전은 IndexedDB(불가한 환경은 localStorage)에만 저장한다.
- 피드백 JSONL은 규칙 ID, 심각도, 프로필, 원문 길이만 포함하며 원문·파일 경로는 넣지 않는다.
- GitHub Issue 열기는 사용자가 명시적으로 버튼을 누를 때만 일어나고, 링크에는 문장을 자동으로 첨부하지 않는다.

## 남는 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 호스트 앱의 로그가 stdin을 기록 | CLI는 진단 메시지에 원문 전체를 넣지 않으며 shell 로그 정책은 사용자가 통제한다. |
| 공유 컴퓨터의 브라우저 저장소 노출 | 설정에서 초안 삭제가 가능하고, 민감한 문서는 시크릿 프로필을 사용한다. |
| 악성 rule pack·overlay | 버전 형식과 범위를 엄격히 검증하고 네트워크 로딩을 지원하지 않는다. |
| 잘못된 자동 수정 | Safe/Review/Abstain 정책, dead-band, 원자적 수정, undo를 사용한다. |

취약점은 공개 이슈가 아니라 [SECURITY.md](../SECURITY.md)의 비공개 절차로 신고한다.
