# 데이터 카드

이 프로젝트의 정확도 개선 데이터는 실행 시 취득하는 원자료와 저장소에 공개하는 파생 산출물을 분리한다. 원자료를 저장소에 복사하지 않고, 출처·라이선스·취득 시점의 SHA-256을 `data/sources.json`에 고정한다.

## 처리 경계

- `redistributable: false`인 자료는 기본 실행에서 제외된다. 검토·학습용 캐시에만 저장하고, 모델·사전·릴리스 아티팩트에 원문을 포함하지 않는다.
- 원자료는 `scripts/acquire-training-data.mjs`로 내려받으며, 해시가 다르면 즉시 실패한다.
- revision에서 추출한 수정은 `scripts/extract-human-edits.mjs`가 `needs_adjudication` 상태로 만든다. 자동 추출 결과는 정답(gold)이 아니다.
- 두 명 이상의 독립 검토와 별도 adjudication을 거친 항목만 평가용 골드 코퍼스로 승격한다.

| ID | 용도 | 라이선스 | 공개 산출물 포함 | 비고 |
| --- | --- | --- | --- | --- |

## 현재 공개된 표준 자산

`dictionaries/standard-ko-v1/`에는 저장소의 MIT 라이선스 회귀 문장과 수동 seed에서 만든 1,407개 표면형의 결정론적 lexicon이 있다. 이 자산은 후보 생성과 API 패리티를 위한 보조 사전이며, 독립 평가 코퍼스나 상용 서비스의 교정 결과를 복제하지 않는다. 원자료가 아닌 파생 TSV·gzip만 공개하고, manifest의 SHA-256과 `scripts/build-standard-lexicon.mjs`로 재현한다.

## 제외 기준

로그인·신청이 필요한 코퍼스, 이용 약관상 자동 대량 수집이 금지된 서비스, 라이선스가 불명확한 데이터, 특정 서비스의 교정 결과를 복제한 데이터는 기본 파이프라인에 넣지 않는다. 공개 평가셋에 포함할 때는 원문 대신 최소 인용·해시·메타데이터와 독립 검토 기록만 남긴다.
